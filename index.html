What it does

从本地服务到公网入口，保持短路径和可控边界。

01

一条命令选择入口协议

默认生成公网 HTTPS 地址；需要直连 SSH 或数据库等非 HTTP 协议时，可以切到 ssh 或 tcp 四层入口。

02

访问策略在代理层执行

Basic Auth、Bearer Token、IP allowlist / denylist 和临时链接都在 Sealtun proxy 层生效，公开预览也能保留边界。

03

模板、声明和导出可以复用

sealtun.yaml 支持 template 生成、dry-run、diff、apply、ttl、多隧道和 export 回写；团队共享配置不用从头拼参数。

Latest capabilities

最新功能覆盖入口、分享、域名、工作台和配置回收。

Sealtun 现在不只是把 Web 页面发出去。它可以管理公网协议、临时访问、域名证书、账号环境和运行状态，也能把已经运行的隧道反向整理成 YAML。

Entrance modes

HTTPS、SSH、TCP 三种公网入口

Web 预览继续走 HTTPS；本地 sshd 可以用 NodePort 直连；数据库、队列和调试服务可以用通用 TCP 入口。

sealtun expose 3000 --protocol ssh --protocol tcp
Domains

域名先 plan，再 add 和 verify

domain plan 先生成 CNAME 指引，domain add 可以等待 DNS 生效后绑定域名，并继续检查 Ingress 与证书状态。

domain plan domain add --wait domain verify --wait
Share

已有 HTTPS 隧道可以临时分享

share create/list/revoke 为隧道生成自动失效的访问链接，URL 只在创建时显示一次，token 不会在列表里泄漏。

Workbench

Dashboard 不只是只读面板

本地工作台可以创建 HTTPS/SSH/TCP 隧道，执行 YAML dry-run/diff/apply，查看日志指标事件，并管理域名和 cleanup。

Doctor

单条隧道诊断更直接

doctor <tunnel-id> 会把本地端口、daemon、远端 Pod、Service、Ingress 和证书问题串起来，并给出下一步建议。

Template & export

从模板开始，也能从现状导出

template https/ssh/tcp/mysql/postgres/redis/mqtt 生成命令和 YAML；export 可把本地 session 安全导出回 sealtun.yaml。

Install

AI 用 Skill，人用 CLI，两条路径都很短。

先装 Skill，让 AI 会用 Sealtun；需要自己操作时，再用 npm 或 npx 安装 CLI。 团队共享入口可以写进 sealtun.yaml，用 dry-run 和 diff 先看清变更，再 apply。

npx skills add https://github.com/gitlayzer/sealtun

# Then ask your AI agent:
# "Expose localhost:3000, create a review share, then export sealtun.yaml."
npm install -g sealtun
sealtun login gzg --profile demo

sealtun expose 3000
sealtun expose 22 --protocol ssh
sealtun expose 5432 --protocol tcp
sealtun expose 3000 --domain app.example.com

# Create CNAME app.example.com -> <sealos-host>
sealtun domain plan <tunnel-id> app.example.com
sealtun domain add <tunnel-id> app.example.com --wait
sealtun domain verify <tunnel-id> --wait --timeout 5m
sealtun domain doctor <tunnel-id>
export SEALTUN_BASIC_AUTH_PASSWORD='change-me'

sealtun expose 3000 \
  --basic-auth-user admin \
  --basic-auth-password-env SEALTUN_BASIC_AUTH_PASSWORD

sealtun share create <tunnel-id> --name review --ttl 2h
sealtun share list <tunnel-id>
sealtun share revoke <tunnel-id> review
sealtun template postgres --name db
sealtun template redis --name cache

sealtun export --all -o sealtun.yaml
sealtun export --all --include-secret-placeholders

sealtun apply -f sealtun.yaml --dry-run
sealtun diff -f sealtun.yaml
sealtun apply -f sealtun.yaml
